这篇是一份持续更新的清单，记录我截止到目前为止认为**最有用的网站和 App**。

> 说明：文中「不翻墙」即国内可直接使用；「翻墙」类需要全程开 VPN。价格以标注时的实际售价为准。

## 日常类

### 不翻墙

- **微信、QQ**：不用多说
- **百度贴吧**：可以用来查资料、找资源
- **小黑盒**：游戏资讯与社区

### 翻墙

1. **VPN 推荐**：<https://tutu.tutugood.store/>，18 元 60G 不限时。推荐选付费的，免费的不但网速慢还不安全
2. **注册谷歌账号**：<https://account.google.com/>，手机短信验证可以填国内手机号（最好是中国移动）
   - 实在不行：<https://sms-activate.io/?ref=10903612> 购买手机号
   - 还不行的话：<https://universalbus.cn/?s=olLxMA23uH> 直接购买谷歌账号（也可以手机版 OurPlay 上购买）
   - 参考视频：[YouTube](https://youtu.be/q0D8NK3rJVA?si=63vWDLW-GqtmEI2d)
3. 注册完成后即可登录 YouTube、谷歌全家桶等服务，无障碍访问外网

**Google Play 会员购买**基本没戏：手机版用不了礼品卡（会锁卡），电脑版基本需要外国银行卡。

> ⚠️ **Google Play 礼品卡千万别买**——买了也用不了，等于被诈骗（亲身经历）。

如果非要用虚拟卡：<https://i.bebingocard.com/login?code=UPHSP888>（详细视频：[YouTube](https://youtu.be/rKskV4jFrO8?si=-RxYYr-4TEh81PUh)）。但**不太推荐**：提供商可能随时跑路，钱拿不回来还可能连累账号被封。

### 订阅外网服务的正路：美区 Apple

最稳的还是 **iPhone / iPad 上购买**：

1. 必须有**美区 App Store**。注册美区账号有两种方式：
   - **一：直接换区**（仅适合中国大陆→美国）：打开 App Store → 右上角账户 → 点自己的用户名/头像 → 输密码 → 点**国家/地区** → 更换到美国 → 付款方式选**无** → 填身份信息（去 Google 搜"地址生成器(美国) "，按要求填即可）→ 完成
   - **二：注册 Apple ID 时直接选美国**（适合所有用户）。具体流程：[Apple 官方指南](https://support.apple.com/zh-cn/108647?device-type=iphone)，注意国家/地区选美国，信息同样用地址生成器
2. **购买美区 App Store 礼品卡**：支付宝搜索 **Pockytshop** 选 App Store 礼品卡（没有支付宝的话在京东/淘宝搜索"App Store 礼品卡"）→ 填金额 → 支付
3. **充值**：打开 App Store → 右上角账户 → **兑换充值卡或代码** → 填入代码 → 输密码 → 成功
4. **使用**：以上充的美金只能在 App Store 消费，要对其他 App 订阅还要：打开**钱包** → 右上角加号 → 曾添加过的卡片 → 点 **Account** 绑定 → 之后就能购买其他应用的订阅了

在 iPhone 上买订阅比 Google Play 安全、方便得多。

### 更省事的用法：API 方式

其实也可以用 API 达成同样效果，**不需要 VPN**：

1. 电脑上下载并注册登录 **Cherry Studio**
2. 打开 <https://yunwu.ai> → 注册 → 充值界面充值
3. 点**控制台 → API 令牌 → 复制**
4. 回到 Cherry Studio → 设置 → 把 API 令牌粘贴到对应 AI 上 → 即可使用
